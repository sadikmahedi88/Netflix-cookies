# 🎬 Netflix Cookies Checker

Advanced Netflix cookies checker written in Python.  
Designed for validating Netflix session cookies, detecting subscription plans, extracting profile information, and saving organized results with fast multi-threaded performance.

---

## ⚡ Features

- 🍪 Netflix cookies validation  
- 💎 Premium / Ultra HD plan detection  
- 👤 Profiles extraction  
- 🌍 Region & country detection  
- 📺 Subscription information analyzer  
- ⚡ Fast multi-threaded checker  
- 📊 Live CPM & statistics  
- 📂 Automatic hits saving  
- 🎨 Beautiful colorful terminal UI  
- 📢 Telegram notifications support  
- 🔥 Fast cookies processing engine
